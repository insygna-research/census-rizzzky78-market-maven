# Features

**Route / access:** `/features`, reached from the "Features" link in the navigation menu and footer.
**Part of:** [Project root README](../../../../README.md)

## Purpose

Showcases each of Maven's core AI tools in action so visitors can see what the product does before signing up.

## What the user sees

A hero introduction followed by five video showcases, each pairing an autoplaying looping demo clip with a title and description: **AI Product Picks** (recommendations), **Find Products Fast** (search), **Deep Product Insights** (product details), **Compare Side-by-Side** (comparison), and **User Inquiry** (clarifying questions). A social-sharing row (Facebook, Twitter, LinkedIn icons) sits below. A sticky banner also links to the Maven Webpage v2 showcase.

## What the user can do

Watch each auto-playing video demo as it scrolls into view, and use the social share icons (currently placeholder links).

## Flow

Reached from the navigation bar or footer. Pairs with [Cookbook](../cookbook/README.md) (how to use the tools) and [Workflow](../workflow/README.md) (how the tools work internally).
